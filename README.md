# Intelligent Industrial Spare Parts Demand Prediction Platform

## Industry Context
Manufacturing companies need spare parts to keep equipment working. Overstocking increases storage costs, while shortages can cause equipment downtime.

## Problem Statement
This project aims to predict spare-parts demand using equipment history, maintenance schedules, consumption patterns, and part criticality.

## Objectives
- Track spare-parts usage.
- Monitor equipment maintenance.
- Identify critical components.
- Forecast spare-parts demand.
- Generate replenishment alerts.
- Analyze inventory trends.

## Technologies
- Python and FastAPI
- MySQL
- Git and GitHub
- Docker and Docker Compose
